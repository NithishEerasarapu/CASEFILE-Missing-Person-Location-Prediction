# CASEFILE: AI-Powered Missing Person Investigation and Location Prediction System

## Project Overview

CASEFILE is an academic machine learning project that analyzes GPS movement patterns and estimates probable locations using machine learning techniques.

The project demonstrates how historical GPS data can be processed, analyzed, clustered, and used for location and route prediction.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- K-Means Clustering
- Isolation Forest
- Markov Chain
- Flask
- Streamlit
- Folium

## Machine Learning Techniques

### 1. K-Means Clustering
Groups GPS coordinates into geographical movement clusters.

### 2. Isolation Forest
Identifies unusual movement patterns in the GPS dataset.

### 3. Random Forest
Estimates probable latitude and longitude using historical movement features.

### 4. Markov Chain
Analyzes transition probabilities between different location clusters.
